# astrbot_plugin_group_bible_gacha · 群圣经抽卡

一个 AstrBot 插件：把群里的「名场面」变成可以抽的圣经。

- **🎴 抽卡**：发 `/抽卡`，机器人把 **群精华消息**（通过 NapCat 的 `get_essence_msg_list` 接口实时获取）和 **圣经池**（群友投稿）**合并成一个候选集均匀随机**抽一条原文发送展现——每条内容被抽中的概率相同，文字、图片、表情都还原；`/抽卡 精华` 会绕过缓存强制拉取最新精华列表。
- **🙏 投稿**：发 `/投稿 文字`（可带图）或 **回复一条消息发 `/投稿`**，把该消息直接收进本群圣经池（无需审核，自动查重），立刻就能被抽到。
- **👉 戳一戳回复**：戳一戳机器人，随机回敬一条圣经（参考 HakuBot poke_reply 的思路：分群开关 + 冷却 + 兜底文案）。
- **📋 群聊白名单**：配置里填群号即可限制插件只在指定群生效，留空则所有群生效。
- **🛡️ 管理**：群管理员可移除不当内容、按群开关功能；AstrBot 管理员（SU）可一键把群精华导入圣经池、重置数据。

适配 AstrBot **v4.x**（基于 v4.29 源码 API 开发）+ NapCat（OneBot v11 / aiocqhttp 协议端），仅依赖 AstrBot 自带能力，无第三方依赖。

## 指令一览

| 指令 | 说明 |
| --- | --- |
| `/抽卡` | 随机抽一条圣经；`/抽卡 精华`、`/抽卡 池` 可指定来源 |
| `/投稿 文字` | 投稿文字（消息可同时带图片），直接入池 |
| 回复消息 + `/投稿` | 把被回复的消息（含图片）投进圣经池 |
| `/圣经池` | 查看本群圣经池概况与最近入库 |
| `/圣经预览 编号` | 预览圣经池里的某条 |
| `/圣经移除 编号` | 把某条移出圣经池（群管理员/SU） |
| `/圣经开关 抽卡\|投稿\|戳一戳 开\|关` | 分群功能开关（群管理员/SU） |
| `/圣经状态` | 查看本群开关与池子状态 |
| `/圣经导入` | 把本群精华消息导入圣经池（仅 SU） |
| `/圣经重置 确认` | 清空本群全部数据（仅 SU） |
| `/圣经帮助` | 查看指令一览 |

> 指令前缀以 AstrBot 配置的唤醒前缀为准（默认 `/`），@机器人 也可以唤醒。

## 群聊白名单

在 WebUI「插件管理 → 群圣经抽卡 → 插件配置」的 **群聊白名单** 里填群号（一行一个）：

- **留空**：插件在所有群生效（默认）。
- **非空**：插件只在列表内的群生效；不在白名单的群里，指令与戳一戳都会被静默忽略（私聊不受白名单限制，但群圣经功能本身需要在群里用）。

## 部署（AstrBot + NapCat，Ubuntu 2H2G）

1. 确认 AstrBot 已通过 **aiocqhttp** 适配器接入 NapCat（NapCat 端开 OneBot v11 正向/反向 WebSocket 均可）。
2. 把本插件放进 AstrBot 的插件目录：

   ```bash
   git clone https://github.com/Mizhiawa/astrbot_plugin_group_bible_gacha.git \
     /opt/AstrBot/data/plugins/astrbot_plugin_group_bible_gacha
   # Docker 部署则放进挂载的 data/plugins/ 目录
   ```

   也可以在 WebUI「插件管理」里从仓库直接安装。
3. 在 WebUI 重载插件（或重启 AstrBot），日志出现 `[群圣经] 插件已加载` 即成功。
4. 在 WebUI「插件管理 → 群圣经抽卡 → 插件配置」里按需调整抽卡来源、冷却时间、白名单、戳一戳文案等（所有配置都有默认值，零配置可用）。
5. 机器人需要在目标群里能收到 `notice` 事件（NapCat 默认上报）；**获取群精华**、**收发消息** 权限正常即可。

### 2H2G 服务器说明

- 本插件把圣经池存为 JSON 文件、图片存本地磁盘（`data/plugin_data/astrbot_plugin_group_bible_gacha/`），不引入数据库；所有文件 IO 都走线程池，不阻塞事件循环。
- 群精华列表默认缓存 10 分钟，冷却时间默认抽卡 15s / 戳一戳 30s / 投稿 60s，避免群多时打爆 NapCat。
- 圣经池每群默认上限 500 条，超出自动淘汰最旧条目（含图片），磁盘占用可控。

## 数据与隐私

- `data/plugin_data/astrbot_plugin_group_bible_gacha/`
  - `pool.json`：各群圣经池
  - `settings.json`：分群开关
  - `images/`：投稿与导入的图片

删除对应群的数据文件或在群内 `/圣经重置 确认` 即可彻底清除该群数据。

## 常见问题

- **`/抽卡` 没反应**：先确认本群在白名单里（留空则全群生效）、抽卡开关是开的、不在冷却中。
- **`/抽卡` 的概率**：精华消息和圣经池条目合并后均匀随机，每条内容概率相同（比如 100 条精华 + 5 条投稿，投稿被抽中概率就是 5/105）。
- **`/抽卡 精华` 提示为空**：该指令会绕过缓存强制拉取最新精华列表；若仍报「获取群精华失败」，通常是 NapCat 版本过旧不支持 `get_essence_msg_list` 或机器人无权查看，升级 NapCat 后重试。普通 `/抽卡` 的精华列表默认缓存 10 分钟（空结果只缓存 1 分钟）。
- **戳一戳没有反应**：确认总开关与分群开关都开着、本群在白名单里、不在冷却中；NapCat 需上报群 notice 事件（默认开启）。只有戳**机器人本人**才会回敬。
- **精华里的图片显示 `[图片]`**：该条消息过旧，NapCat 已拿不到图片直链；重新加精或让群友投稿即可。
- **投稿提示「已经在池子里」**：同一内容（同人同文同图数）不会重复入库。

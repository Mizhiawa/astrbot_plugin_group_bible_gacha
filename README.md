# astrbot_plugin_group_bible_gacha · 群圣经抽卡

一个 AstrBot 插件：把群里的「名场面」变成可以抽的圣经。

- **🎴 抽卡**：发 `/抽卡`，机器人从 **群精华消息**（通过 NapCat 的 `get_essence_msg_list` 接口）和 **圣经池**（群友投稿）中随机抽一条原文发送展现，文字、图片、表情都还原。
- **🙏 投稿**：发 `/投稿 文字`（可带图）或 **回复一条消息发 `/投稿`**，把该消息投进本群圣经池，管理员审核后入库。
- **👉 戳一戳回复**：戳一戳机器人，随机回敬一条圣经（参考 HakuBot poke_reply 的思路：分群开关 + 冷却 + 兜底文案）。
- **🛡️ 管理**：群管理员可审核/开关本群功能；AstrBot 管理员（SU）可一键把群精华导入圣经池、重置数据。

适配 AstrBot **v4.x**（基于 v4.29 源码 API 开发）+ NapCat（OneBot v11 / aiocqhttp 协议端），仅依赖 AstrBot 自带能力，无第三方依赖。

## 指令一览

| 指令 | 说明 |
| --- | --- |
| `/抽卡` | 随机抽一条圣经；`/抽卡 精华`、`/抽卡 池` 可指定来源 |
| `/投稿 文字` | 投稿文字（消息可同时带图片） |
| 回复消息 + `/投稿` | 把被回复的消息（含图片）投进圣经池 |
| `/圣经池` | 查看本群圣经池概况与最近入库 |
| `/圣经预览 编号` | 预览某条待审核投稿或圣经池条目 |
| `/圣经审核` | 列出待审核投稿（群管理员/SU） |
| `/圣经通过 编号\|全部` | 通过投稿，收入圣经池 |
| `/圣经拒绝 编号\|全部` | 拒绝并清理投稿 |
| `/圣经移除 编号` | 把某条移出圣经池 |
| `/圣经开关 抽卡\|投稿\|戳一戳 开\|关` | 分群功能开关（群管理员/SU） |
| `/圣经状态` | 查看本群开关与池子状态 |
| `/圣经导入` | 把本群精华消息导入圣经池（仅 SU） |
| `/圣经重置 确认` | 清空本群全部数据（仅 SU） |
| `/圣经帮助` | 查看指令一览 |

> 指令前缀以 AstrBot 配置的唤醒前缀为准（默认 `/`），@机器人 也可以唤醒。

## 部署（AstrBot + NapCat，Ubuntu 2H2G）

1. 确认 AstrBot 已通过 **aiocqhttp** 适配器接入 NapCat（NapCat 端开 OneBot v11 正向/反向 WebSocket 均可）。
2. 把本文件夹整个放进 AstrBot 的插件目录：

   ```bash
   # 二进制部署的默认插件目录
   cp -r astrbot_plugin_group_bible_gacha /opt/AstrBot/data/plugins/
   # Docker 部署（挂载的 data 目录）
   cp -r astrbot_plugin_group_bible_gacha /your/astrbot/data/plugins/
   ```

   也可以在 WebUI「插件管理」里从本地/仓库安装。
3. 在 WebUI 重载插件（或重启 AstrBot），日志出现 `[群圣经] 插件已加载` 即成功。
4. 在 WebUI「插件管理 → 群圣经抽卡 → 插件配置」里按需调整冷却时间、抽卡来源、戳一戳文案等（所有配置都有默认值，零配置可用）。
5. 机器人需要在目标群里能收到 `notice` 事件（NapCat 默认上报）；**获取群精华**、**收发消息** 权限正常即可，加精/审核操作仍由群管理员在 QQ 客户端完成。

### 2H2G 服务器说明

- 本插件把圣经池存为 JSON 文件、图片存本地磁盘（`data/plugin_data/astrbot_plugin_group_bible_gacha/`），不引入数据库；所有文件 IO 都走线程池，不阻塞事件循环。
- 群精华列表默认缓存 10 分钟，冷却时间默认抽卡 15s / 戳一戳 30s / 投稿 60s，避免群多时打爆 NapCat。
- 圣经池每群默认上限 500 条，超出自动淘汰最旧条目（含图片），磁盘占用可控。

## 数据与隐私

- `data/plugin_data/astrbot_plugin_group_bible_gacha/`
  - `pool.json`：各群已入库圣经
  - `pending.json`：各群待审核投稿
  - `settings.json`：分群开关
  - `images/`：投稿与导入的图片

删除对应群的数据文件或在群内 `/圣经重置 确认` 即可彻底清除该群数据。

## 常见问题

- **`/抽卡` 提示「获取群精华失败」**：NapCat 版本过旧不支持 `get_essence_msg_list`，或机器人账号无权查看；升级 NapCat 后重试。
- **戳一戳没有反应**：确认总开关与分群开关都开着、不在冷却中；NapCat 需上报群 notice 事件（默认开启）。只有戳**机器人本人**才会回敬。
- **精华里的图片显示 `[图片]`**：该条消息过旧，NapCat 已拿不到图片直链；重新加精或让群友投稿即可。
